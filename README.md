# Deterministic Bifurcation Exploration Framework

## Overview

This repository contains a deterministic, single-process framework for exploring the behavior of a periodically forced nonlinear dynamical system through numerical integration and parameter sweeps.

The primary output is a **Poincaré (stroboscopic) bifurcation diagram**, generated by integrating the system over many forcing periods while varying a single coupling parameter.

The implementation is intended as a **numerical exploration tool** rather than a validated physical simulation. It provides a reproducible foundation for studying nonlinear dynamics, attractor evolution, and parameter-dependent behavior.

---

# Purpose

The objective of this project is to provide a clean and reproducible implementation for investigating nonlinear dynamics using:

- deterministic parameter sweeps
- high-order adaptive numerical integration
- stroboscopic (Poincaré) sampling
- transient removal
- bifurcation visualization

The framework is designed to be easily extended with additional diagnostics such as Lyapunov exponents, continuation methods, basin analysis, or parameter optimization.

---

# Mathematical Model

The implemented equations define a **modified cyclic quadratic dynamical system** with:

- a Halvorsen-inspired quadratic core,
- a symmetric cubic periodic coupling term,
- nonlinear radial damping.

The governing equations are

\[
\dot{x}=f_x(x,y,z,t)
\]

\[
\dot{y}=f_y(x,y,z,t)
\]

\[
\dot{z}=f_z(x,y,z,t)
\]

where the periodic forcing strength is controlled by the coupling parameter

\[
m.
\]

The equations are intended for numerical investigation of nonlinear dynamics and should not be interpreted as a validated physical model without independent derivation and experimental verification.

---

# Numerical Method

The implementation uses SciPy's

```
solve_ivp(method="DOP853")
```

which is an adaptive eighth-order Runge–Kutta integrator well suited for smooth, non-stiff systems.

For each parameter value:

1. The system is integrated over many forcing periods.
2. States are sampled once every forcing period (Poincaré map).
3. Initial transient behavior is discarded.
4. The remaining points are plotted to form the bifurcation diagram.

---

# Deterministic Architecture

Unlike earlier multiprocessing implementations, this version performs a simple serial parameter sweep.

```python
for m in m_values:
```

Advantages include:

- deterministic execution
- identical results across runs
- no multiprocessing serialization issues
- Windows, Linux, and macOS compatibility
- simplified debugging
- easier reproducibility

The implementation intentionally prioritizes reproducibility over raw execution speed.

# Current Limitations

The current implementation intentionally keeps the numerical workflow simple.

Limitations include:

- fixed transient length
- fixed parameter spacing
- no adaptive continuation
- no checkpointing
- no event detection
- no convergence testing
- no automatic bifurcation detection
- no Lyapunov exponent computation
- no uncertainty analysis

These limitations do not reduce the usefulness of the code for exploratory numerical studies, but they should be considered when interpreting results.

# Reproducibility

The framework is deterministic provided that:

- the same initial condition is used,
- identical parameter values are supplied,
- the same solver tolerances are maintained,
- identical versions of NumPy and SciPy are used.

Because the implementation is serial, execution order is fixed and reproducible across platforms.
